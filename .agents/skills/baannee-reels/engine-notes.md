## What the engine does (reels-engine)
- **Card cover (default, commit 1e240eb, app/cover.py):** `hook.style` "card" (default) draws a full opaque cover in the same look as the page's image posts: light-blue dotted background, blue `tag` pill top-left (default ทริคบ้านน่ารู้), house logo + brand top-right (มีดี in blue), scene 1's svg with its full-size background rect and full-width floor strip removed (trimmed, soft shadow under it), big black title with *asterisk* words in blue, `badge` as a big orange line, white card with up to 3 `points` (blue check circles), grey `note`, footer "แก้ปัญหาในบ้าน · ของใช้ดีบอกต่อ" + brand. Shown for HOOK_SECONDS then fades into scene 1; subtitles hidden while it is up. Frame 0 = cover_url.
- **Pop cover (legacy, `hook.style` "pop", commit 083f76b):** optional `hook: {title, tag, badge}` draws a big bold title over a dimmed scene 1 for the first HOOK_SECONDS (3.0) — fully visible from frame 0 so the first frame works as the cover; `title` = 2 lines split by \n, words in *asterisks* get a yellow highlight; red `tag` pill above, green `badge` pill + bouncing arrow below; scene 1 card does not pop in and its headline waits until the hook fades. Frame 0 is also saved as `cover_url` (/files/<id>.jpg). Step pill 54 px, headline pill 76 px.
- `POST /render` (header X-API-Key) with `{hook?, scenes:[{text, headline?, step?, svg?, image_url?}], product_image_url, music_style?, seed?, voice_id?, callback_url?, meta?}` → `{job_id}`; `GET /jobs/{id}` → status, video_url, duration, chars, credits_left, music, tts_cache_hits, tts_new, chars_billed. Files served at /files/<id>.mp4, deleted after KEEP_DAYS (3).
- Total scene text ≤ MAX_CHARS (set to 700 in .env; code default 320) else 422. Each scene is voiced separately, then a SCENE_GAP pause (0.2 s; 1.3 s after the last), so very short scenes sound choppy. Each scene: image card (inline `svg` rasterized with cairosvg, else image_url, else brand background; last scene falls back to product_image_url), headline pill, step pill, karaoke subtitles (highlight per space-separated phrase using ElevenLabs character timestamps), CTA box on the last scene. Scene 1 pops in; later scenes slide in from alternating sides with a small tilt.
- **Natural cartoon motion (commit ba8abc0, full docs at the top of app/anim.py, worked example examples/scene_natural_motion.svg):** `data-anim="keys"` keyframes `data-keys="t x y [rot] [scale|sx*sy] [opacity] [ease]; ..."` (ease inout/out/in/back/bounce/linear, `data-loop="1"` repeats) for acting like reach → scrub → lift; joints by nesting keys groups (shoulder > elbow > hand, each with its own pivot data-cx/cy); loop motions get natural variation (`data-jitter`, default 0.3); pop squashes and stretches, slidein overshoots; `scrubout` = child stain blobs vanish one by one in random order; particle emitters `data-anim="emit" data-kind=bubble|drop|stream|steam|dust|sparkle` (one template shape, data-count, data-spread, data-amp, data-speed, data-delay); camera on the svg root `data-camera="push"` (default)|pull|pan-left|pan-right|none + `data-focus="x y"`, `data-depth` on background groups (0.5) gives parallax. Every svg scene renders live (camera move even with no data-anim); ~30 s render for a 17 s clip.
- **Animated scenes** (app/anim.py): any `<g>`/shape in the svg with `data-anim` is animated frame by frame on the VPS (cairosvg per frame, no browser, ~40 s render for a 27 s clip). Static svgs/images get a slow Ken Burns zoom instead. Motions: `wipe` (left-right, data-amp px), `scrub` (small circles), `bob` (up-down), `float`, `shake`; `sway` / `spin` / `pulse` (need pivot `data-cx` `data-cy`); `rise` (up + fade loop: steam, smell, bubbles), `drip` (fall + fade loop: drops), `blink`; one-shot `pop` (needs data-cx/cy, data-delay), `fadein` / `fadeout` (data-delay, data-dur; fadeout = dirt being cleaned), `slidein` (data-from left|right|top|bottom). Common: `data-speed` (cycles/s), `data-delay` (s), `data-phase` (0–1). Motions can be nested (a wipe group containing a bob group).
- **Drawing library + mascot (commits 2fa7093, 80fe023, docs at the top of app/assets.py):** draw once, reuse forever. `<g data-asset="name" transform="translate(x y) scale(s)"/>` inserts a library drawing (origin = bottom-centre, sizes in scene units; data-anim on the same <g> still works). Library = assets/*.svg + assets/catalog.json on branch reels-engine (built into the image) + DATA_DIR/assets (auto-saved on the VPS) + GitHub raw fallback; GET /assets lists it. Special assets: `zee` = page mascot น้องซี (แบบ A: spiky hair, blue shirt, white apron with house patch; chosen by BAS Nov 2026), ~675 tall at scale 1, `data-expr="0 shock; 3.6 point"` pose timeline (shock|happy|point|hold|normal), `data-hold="sponge"` for hold, blinks/breathes, pops on pose change, lip-syncs to the voice loudness automatically (`data-talk="0"` to stop); `arm` = jointed arm, shoulder at origin, hand at (-355,205), `data-shoulder-keys` / `data-elbow-keys` / `data-joint-delay` / `data-hold` / `data-hold-scale` / `data-sleeve`. A group marked `data-save="snake_name" data-desc="..."` renders normally AND is stored in the library if the name is new (job result `assets_saved`). Cover drops background groups with data-depth < 1. Referencing instead of drawing cut the demo scenes from ~25.8 KB to ~3.6 KB of svg.
- Voice: ElevenLabs `/text-to-speech/{voice}/with-timestamps`; **sentence cache** in data/tts_cache (same text+voice+model+stability = no credits; unused 120 days → deleted). Falls back to ELEVEN_FALLBACK_MODEL when credits < 15,000, and back to the main model if the fallback fails. **Natural-voice settings (confirmed good, Nov 2026, commit 8e03721):** TTS_STITCH=1 sends the neighbouring scenes as previous_text/next_text so intonation flows across scenes (not billed; auto-disabled if the model refuses; cache key stays text-only so CTA lines stay cached); VOICE_SPEED=1.2 (0.7–1.2; raised from 1.1 in Nov 2026 because BAS wanted faster speech) for brisker, less drawn-out speech via ElevenLabs speed, with a pitch-preserving ffmpeg atempo fallback that rescales subtitle timestamps (changing speed re-generates cached audio once); SCENE_GAP=0.2. Cost ≈ 0.44 credits/char → ~200–230 per Reel; plan has 129,000 credits/month (≈ 45k/month at 7/day, ≈ 65k at 10/day).
- Music: `bright` (default) = many royalty-free upbeat explainer flavors (rhythm instrument, lead, drum kit, arp, 100–128 BPM, key, progression, melody); anti-repeat history in data/music_history.json (no repeat of rhythm/lead/kit combo in last 6 clips; rhythm and kit always differ from the previous clip). `lofi` optional. Ducking: MUSIC_UNDER_VOICE (0.07) / MUSIC_IN_GAPS (0.20) in .env, plus a voice-band cut on the music.
- **Cover colours (commit 9efad27):** each card cover gets a random palette (orange/green/purple/blue/rose, the same 5 as the image-post template: accent = tag, logo, highlighted title words, ticks; second colour = the sub line) and a random background pattern (dots/blobs/tiles/shapes/waves/poly/hex). History in data/cover_history.json: palette never the same as the previous clip, pattern not in the last 3. Force one with `hook.palette` / `hook.art` (normally leave both out).
- Output follows Facebook Reels spec: 1080x1920, 30 fps, H.264 High@4.1, closed GOP 2 s, AAC-LC stereo 48 kHz, loudnorm −14 LUFS.
